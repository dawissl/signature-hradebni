# Generátor e-mailového podpisu

Jednoduchý nástroj pro generování e-mailových podpisů pro zaměstnance školy.

## ✨ Funkce
- vyplnění formuláře (jméno, pozice, telefon, email)
- okamžitý náhled podpisu
- kopírování podpisu jako formátovaného obsahu (funguje v Gmailu)

## 🚀 Použití
1. Otevři stránku https://dawissl.github.io/signature-hradebni/
2. Vyplň údaje
3. Pomocí tlačítka si vygeneruj podpis
4. Klikni na „Kopírovat podpis“
5. V Gmailu:
   - Nastavení → Podpis
   - vlož (Ctrl+V)
